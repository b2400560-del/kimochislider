## テーマA：PMMの役割と事業インパクト

### A-1
```
いい製品なのに売れない会社に足りないのは
たいてい「機能」じゃなく「伝え方の設計」

・誰に売るか
・何と比べて選ばれるか
・なぜ今買うべきか

これを決めて
開発・営業・マーケを同じ言葉でつなぐ人がPMM

作る人と売る人の間に
ちゃんと橋をかける仕事
```

### A-2
```
PdMとPMMの違いを一言で

PdM＝正しいものを作る
PMM＝作ったものを正しく売れる状態にする

PdMは「何を作るか」
PMMは「誰に、どう価値を伝えるか」

どちらかが欠けると
いい製品が埋もれるか
売れても続かないかのどちらか
```

### A-3
```
PMMの成果はいいね数では測れない

見るべきは
・商談化率
・受注率
・新機能の利用率
・解約率

全部売上に直結する数字

ブランド認知だけを追うなら広報でいい
PMMは「選ばれる理由」を数字で証明する仕事
```

### A-4
```
PMMがいない会社で起きがちなこと

・営業ごとに説明がバラバラ
・LPと商談で言ってることが違う
・新機能を出しても誰も使わない
・失注理由が誰にもわからない

製品じゃなく「言葉」がボトルネックになってる

これを直すのがPMMの最初の仕事
```

### A-5
```
スタートアップでPMMを置くべきタイミング

・機能は増えたのに売上が伸びない
・営業が増えて説明がブレ始めた
・競合が出てきて価格で比べられ始めた

1つでも当てはまるなら
「もっと作る」より先に
「どう選ばれるか」を決める時期
```

## テーマB：ポジショニング

### B-1
```
ポジショニングの出発点は自社じゃない

最初に考えるのは
「この製品がなかったら、顧客は何を使う？」

答えは競合とは限らない
Excel、手作業、外注、何もしない

本当のライバルが分かると
伝えるべき強みが一気に絞れる
```

### B-2
```
April Dunfordのポジショニング5要素

1. 競合の代替手段
2. 自社だけの特徴
3. それが生む価値
4. その価値を一番欲しがる顧客
5. 市場カテゴリー

順番が大事
「特徴」からではなく
「代替手段」から考えるのがコツ
```

### B-3
```
「全員がターゲット」は
「誰にも刺さらない」とほぼ同じ意味

ポジショニングは
誰を捨てるかを決めること

狭く絞るほど
・メッセージが鋭くなる
・営業が勝ちやすくなる
・口コミが広がりやすくなる

広げるのは勝ってからでいい
```

### B-4
```
同じ製品でも
「どのカテゴリーで戦うか」で勝敗が変わる

例えば社内チャットツールを
「メールの代わり」と見せるか
「会議を減らすツール」と見せるか

比べられる相手が変われば
価値の伝わり方も
払ってもらえる値段も変わる
```

### B-5
```
ポジショニングとメッセージングは別物

ポジショニング＝市場でどこに立つか
メッセージング＝それをどう言葉にするか

キャッチコピーを先に考えて迷走するのは
立ち位置が決まってないから

コピーに悩んだら
一度ポジショニングに戻る
```

## テーマC：プライシング

### C-1
```
利益を一番動かすレバーは価格

HBRの古典的な分析では
平均的な企業が価格を1%下げると
営業利益は約11%減るとされる

値下げは一瞬
取り戻すのは何年もかかる

「安くすれば売れる」の前に
「なぜ高くても選ばれるか」を考える
```

### C-2
```
価格はコストから決めるものじゃない

・原価＋利益＝自社都合
・競合の横並び＝思考停止
・顧客が得る価値＝本来の基準

「この製品で顧客はいくら得するか」
ここを言葉にできれば
値段の話は交渉じゃなく説明になる
```

### C-3
```
値下げを求められたら
まず疑うべきは価格じゃなく価値の伝わり方

「高い」の本当の意味は
・価値が伝わっていない
・比べる相手を間違えている
・決裁者に説明できない

この3つは
値引きじゃなく伝え方で解決できる
```

### C-4
```
料金プランを3つ並べる理由

人は極端を避けて真ん中を選びやすい

・松：比較の基準をつくる
・竹：本当に売りたいプラン
・梅：入口のハードルを下げる

プラン設計は
値段の一覧じゃなく
顧客の選び方の設計
```

### C-5
```
サブスクで見るべき数字は
新規の数より「解約しない理由」

・使い始めてすぐ価値を感じるか
・使い続けるほど便利になるか
・やめると困るか

ここまで設計できて初めて
集客にお金をかける意味が出る
穴の空いたバケツに水は貯まらない
```

## テーマD：顧客理解（JTBD）

### D-1
```
「ドリルを買う人が欲しいのはドリルではなく穴である」

マーケの有名な格言

さらに言えば
欲しいのは穴でもなく
「棚を付けてスッキリした部屋」かもしれない

機能 → 結果 → その先の気持ち
どこまで掘れるかで提案の質が変わる
```

### D-2
```
クリステンセンのミルクシェイクの話

味を改良しても売上は伸びなかった
調べると朝に買う人が多く
目的は「退屈な通勤を片手で紛らわすこと」

競合は他社のシェイクではなく
バナナやベーグルだった

顧客は商品を買うのではなく
「片付けたい用事」に雇っている
```

### D-3
```
顧客インタビューで聞くべきは
「欲しい機能」じゃなく「過去の行動」

✕ この機能あったら使いますか？
○ 前回この問題が起きた時どうしました？

人は未来の自分について
ほぼ正確に答えられない

事実を聞くと
本当の課題とお金の流れが見えてくる
```

### D-4
```
失注分析は一番安い市場調査

負けた商談には
・誰と比べられたか
・何が決め手だったか
・どこで不安になったか
が全部詰まっている

勝った理由より
負けた理由の方が
ポジショニングの改善点を教えてくれる
```

### D-5
```
BtoBの買い手が営業と会う時間は
購買プロセス全体の約17%（Gartner調査）

残りは
・自分でネットで調べる
・社内で相談する
・情報を比較する

つまり営業がいない場所で
勝負の大半が決まっている

だから営業資料より先に
「自分で調べた時に伝わるか」を整える
```

## テーマE：GTM・ローンチ・営業連携

### E-1
```
新機能リリースで一番もったいないのは
「作ったのに誰も知らない」状態

全部を大きく告知する必要はない

・大型：プレスや記者向け発表まで
・中型：既存顧客へメールとウェビナー
・小型：リリースノートだけ

重さを分けると
本当に大事な発表がちゃんと届く
```

### E-2
```
ローンチの成否は発表日に決まらない

発表日より大事なのは
・営業が説明できる状態か
・サポートが答えられる状態か
・既存顧客に何が変わるか伝えたか

社内に伝わってない機能は
社外にも伝わらない
```

### E-3
```
営業がPMMに一番欲しいものは
きれいな資料ではなく
「競合と比べられた時の返し方」

・相手の強みと弱み
・よくある反論と切り返し
・乗り換えの決め手

1枚にまとめるだけで
営業の勝率は変わる
```

### E-4
```
GTM戦略を一言で言うと
「誰に、何を、どうやって届けて、どう稼ぐか」

・誰に：ターゲット
・何を：価値の言葉
・どうやって：チャネル
・どう稼ぐ：価格と売り方

どれか1つだけ尖っても売れない
4つがかみ合って初めて事業になる
```

### E-5
```
PLGとセールス主導は対立じゃない

・PLG：まず使ってもらい価値を体感させる
・SLG：課題を聞いて導入まで伴走する

小さく始めて
使い方が広がったところで営業が入る

「どっちか」じゃなく
「どこで切り替えるか」を設計するのが今の勝ち筋
```
