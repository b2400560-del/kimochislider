# プロダクトマーケティング X投稿案 v2（6つの型 × 5本）

- 参考：動画「Xでフォロワー0→1000人までを最短で達成するには」で紹介されていた6つの型
  1. 理想像系（A状態→B状態の解像度を上げる）
  2. 学び系（シンプルに学びになる内容）
  3. 肯定する（拡散性が一番高い）
  4. 背中見せる系
  5. 親近感
  6. 権威性
- 文体：です・ます調、「！」あり、くだけた一言も入れて人間らしく
- X無料版の上限（加重280）以内であることを全本スクリプトで確認済み
- ※「背中見せる系」と「親近感」は一人称の体験談です。数字やエピソードは、実際の体験に合わせて書き換えてから投稿してください

## 1. 理想像系（A状態→B状態を見せる）

### 1-1
```
「いい商品なのに売れない…」と悩む人から
「この商品はこの人に、こう伝えれば売れる」と言い切れる人へ！

これがプロダクトマーケターの理想像だと思っています。

必要なのは才能じゃなくて
・顧客の話を聞く
・競合と比べる
・言葉にする
この3つの繰り返しです！
```

### 1-2
```
「会議でなんとなく意見を言う人」から
「顧客の声と数字で会議を動かす人」へ！

プロダクトマーケを学ぶと、ここが一番変わります。

・この機能は誰のため？
・何と比べて選ばれる？
・いくらなら買う？

この3つを聞けるだけで、発言の重みが全然違いますよ！
```

### 1-3
```
値下げでしか売れない状態から
「高くても選ばれる理由」を説明できる状態へ！

HBRの分析では、価格を1%下げるだけで営業利益が約11%減るそうです。

だからこそ、価値を言葉にできる人は本当に強いです！
しかもこれ、練習で身につくスキルなんです。
```

### 1-4
```
「全部の機能を一生懸命説明する営業」から
「お客さんの悩みに一言で刺さる営業」へ！

変えるべきは話す量じゃなくて、伝える順番です。

①お客さんの今の困りごと
②それがなくなった未来
③そのための機能

この順番にするだけで、反応が変わりますよ！
```

### 1-5
```
半年後、こうなっていたいです！

・新しいサービスを見たら3秒で「誰向けか」がわかる
・競合との違いを一言で言える
・値段の理由を説明できる

今はまだ全然できません（笑）
でも全部トレーニングで伸ばせるスキルなので、一緒に目指しましょう！
```

## 2. 学び系（シンプルに学びになる）

### 2-1
```
ポジショニングを考えるとき、最初にやるべきことがあります！

それは「この商品がなかったら、お客さんは何を使うか？」を考えることです。

答えは競合とは限りません。
Excel、手作業、外注、そもそも何もしない…

本当のライバルがわかると、伝えるべき強みが一気に絞れますよ！
```

### 2-2
```
PdMとPMMの違い、一言で言うとこうです！

PdM：正しいものを作る人
PMM：作ったものが正しく売れる状態をつくる人

どちらかが欠けると
「いい商品なのに誰にも知られない」
「売れたけどすぐ解約される」
のどちらかになりがちです。
```

### 2-3
```
お客さんへのヒアリングで、やってはいけない質問があります！

✕「この機能があったら使いますか？」
○「前回この問題が起きたとき、どうしましたか？」

人は未来の自分について、正確には答えられないんです。

過去の行動を聞くと、本当の課題が見えてきますよ！
```

### 2-4
```
料金プランがよく3つある理由、知ってますか？

人は極端を避けて、真ん中を選びやすいんです！

・上のプラン：比べる基準をつくる
・真ん中：一番売りたいプラン
・下のプラン：始めるハードルを下げる

プラン設計は「値段の一覧」じゃなくて「選び方の設計」なんですね！
```

### 2-5
```
有名な「ミルクシェイク」の話が面白いです！

味を改良しても売上は伸びなかった。
調べたら、朝の通勤中に買う人が多かったんです。

目的は「退屈な運転を片手で紛らわすこと」
ライバルは他のシェイクじゃなく、バナナやベーグルでした！

お客さんは商品じゃなく「用事の解決」を買っています。
```

## 3. 肯定する（拡散性が一番高い型）

### 3-1
```
自分の勉強にお金を使うこと、全然悪いことじゃないです！

本1冊2,000円でも、その中の1つの考え方で
・提案が通る
・企画が通る
・売上が変わる
なんてことは普通にあります。

「自己投資しすぎかな…」と迷っている人、むしろ正解だと思いますよ！
```

### 3-2
```
「マーケの専門用語がわからない…」と悩んでいる人、大丈夫です！

用語を知っていることより
「お客さんは何に困ってる？」を考えられることの方が100倍大事です。

それを自然に考えられているなら、もう立派なマーケ思考ですよ！
```

### 3-3
```
新しいサービスを見るたびに
「これ誰向けなんだろう？」
「なんでこの値段なんだろう？」
と考えてしまう人。

それ、めちゃくちゃいいクセです！

プロダクトマーケの仕事って、まさにその疑問を言葉にすることなんです。
その感覚、ぜひ大事にしてください！
```

### 3-4
```
お客さんにいきなり売り込めないこと、悪いことじゃないです！

「もっと話を聞いてから…」と思えるのは
相手のことを考えている証拠です。

実際、強いマーケターほど「売る前に聞く」を大事にしています。
その慎重さ、立派な武器ですよ！
```

### 3-5
```
「ターゲットを絞るのが怖い…」と感じる人。
その気持ち、すごく自然です！

でも絞ることは「誰かを捨てる」ことじゃなくて
「この人を絶対に幸せにする」と決めることなんです。

迷いながらでも決めようとしている時点で、もう前に進んでいますよ！
```

## 4. 背中見せる系（努力・過程を見せる）

### 4-1
```
最近、毎日1つ「身の回りのサービスのポジショニング分析」をやっています！

今日はコンビニのコーヒー。
・ライバル：カフェチェーン、缶コーヒー
・強み：安い、早い、どこにでもある
・誰向け：出勤前の人

10分でできるので、ぜひ一緒にやってみてください！
```

### 4-2
```
プロダクトマーケの勉強を始めて、やってよかったことTOP3です！

1. 本を読んだら1つだけ実践する
2. 気になったLPの言葉をメモする
3. 学んだことをXで発信する

特に3つ目が効きました。
人に説明しようとすると、自分の理解の浅さに気づけるんです（笑）
```

### 4-3
```
今日はApril Dunfordさんのポジショニングの考え方を、身近なアプリに当てはめてみました！

気づいたのは
「強み」から考えると全然まとまらないのに
「代替手段」から考えるとスッと整理できること。

本で読むのと手を動かすのでは、全然違いますね…！
```

### 4-4
```
今週の振り返りです！

・マーケの本を2冊読了
・好きなサービス3つのLPを分析
・友達2人に「なんでそれ使ってるの？」とインタビュー

一番学びが大きかったのはインタビューでした。
「便利だから」の奥に、全然違う理由が隠れてたんです…！

来週も続けます！
```

### 4-5
```
正直、マーケの勉強を始めた頃は
「フレームワークを覚えれば勝てる」と思っていました。

でも実際は、お客さんの話を聞くたびに
自分の仮説がズレていたと気づく毎日です（笑）

それでも少しずつ「当たる」回数が増えてきたのが嬉しいです！
引き続きがんばります！
```

## 5. 親近感（失敗・あるある）

### 5-1
```
マーケの本を読んで「よし、全部わかった！」と思った翌日、
友達に説明しようとしたら全然言葉が出てきませんでした（笑）

インプットしただけで分かった気になるの、あるあるですよね…

なので最近は、読んだら必ず誰かに話すようにしています！
```

### 5-2
```
キャッチコピーを3時間考えて、結局1行も決まらなかった日がありました（泣）

後から気づいたんですが、原因は
「誰に向けて書くか」を決めていなかったことでした。

言葉に悩んだら、一回ターゲットに戻る。
同じ沼にハマっている方、一緒にがんばりましょう！
```

### 5-3
```
「期間限定」とか「残りわずか」を見ると、つい買いそうになるんですよね…！

でもマーケを勉強してから
「あ、これは希少性で押してるな」
と気づいて、一回冷静になれるようになりました（笑）

みなさん最近、思わず買っちゃったものありますか？
```

### 5-4
```
正直に言うと、最初は「PMM」と「PdM」の違いが全然わかっていませんでした…！

名前、似すぎじゃないですか？（笑）

今は
PdM＝作るものを決める人
PMM＝届け方を決める人
と覚えています。

同じように混乱していた方、仲間です！
```

### 5-5
```
友達に「なんでそのアプリ使ってるの？」と聞いたら
「なんとなく」と返ってきて衝撃でした（笑）

でもよく聞くと
「周りがみんな使ってるから」
「通知がうるさくないから」
と本当の理由がポロポロ出てくるんです！

「なんとなく」を深掘りすると、めちゃくちゃ面白いですよ！
```

## 6. 権威性（データ・専門家の知見を借りる）

### 6-1
```
Gartnerの調査によると、BtoBの買い手が営業と会っている時間は、購買プロセス全体のたった17%だそうです！

残りの大半は、自分で調べたり社内で相談したりする時間。

つまり、営業がいない場所で勝負の大半が決まっているんです。
「自分で調べたときに伝わるか」が本当に大事ですね！
```

### 6-2
```
HBRの有名な分析によると、平均的な企業が価格を1%下げると、営業利益が約11%も減るそうです！

値下げは一瞬ですが、取り戻すのは本当に大変です。

「安くすれば売れる」の前に
「なぜ高くても選ばれるのか」を考える。
これがプロダクトマーケの大事な役割です！
```

### 6-3
```
ポジショニングの専門家April Dunfordさんは、まずこう考えるそうです！

「この商品がなかったら、お客さんは何を使うか？」

そこから
①代替手段
②独自の特徴
③それが生む価値
④一番欲しがる人
⑤市場カテゴリー
の順に考えます。

強みから考えないのがポイントです！
```

### 6-4
```
ハーバードのクリステンセン教授は
「人は商品を買うのではなく、片付けたい用事のために商品を雇う」
と言っています！

これが有名な「ジョブ理論」です。

お客さんが本当に解決したいことがわかると、ライバルも伝え方もガラッと変わりますよ！
```

### 6-5
```
マーケティングの世界で有名な格言があります！

「ドリルを買う人が欲しいのは、ドリルではなく穴である」

さらに言えば、欲しいのは穴でもなく
「棚を付けてスッキリした部屋」かもしれません。

機能→結果→その先の気持ち
どこまで掘れるかで、提案の質が変わります！
```
